跳到 750 设计稿
UI 5.0 / 750px

把交互原型收敛成小程序设计稿语境，所有核心尺寸回到 750 基准。

这版不再强调“浏览器里的一台手机”，而是直接把首页、列表、提醒、我的四个小程序主页面收进同一张 750 宽画板中。字号、留白、底部导航、抽屉和按钮尺寸都按设计稿尺度放大，方便继续往 Taro 或 Figma 组件规范落地。

设计基准画板宽 750，高 1624，安全边距 32，底部安全区 44。
组件尺寸主按钮 72 高，标签 42 高，TabBar 92 高，更接近小程序出图。
视觉语言保留医疗可信感，但把色彩和层次做得更像正式交付稿。
适配说明开发时可按 1px = 1rpx 的设计稿思路换算到 375 逻辑宽屏幕。
风险优先首页 hero 和任务卡仍然先展示逾期、今日、未来 7 天的提醒。
闭环更短从卡片到详情到底部抽屉，完成开药和编辑提醒都不跳离当前流程。
组件可复用卡片、标签、统计块、表单项统一了圆角和密度，后续更容易拆成设计系统。
