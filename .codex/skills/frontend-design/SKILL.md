此技能旨在引导创作出与众不同的、生产级的前端界面，避开平庸的“AI 工业味（AI slop）”审美。在实现可运行的代码时，需对美学细节和创意选择倾注极高的关注。

用户会提供前端需求：一个待构建的组件、页面、应用程序或界面。他们可能会提供关于用途、受众或技术限制的背景信息。

## 设计思考

在编写代码之前，请先理解背景并确立一个大胆的美学方向：

- **目的**: 这个界面解决了什么问题？谁在使用它？
- **风格**: 选择一个极端风格：极简主义、极繁主义、复古未来主义、有机/自然、奢华/精致、趣味/玩具感、杂志/杂志风格、粗犷/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等等。风格选择众多。您可以从中汲取灵感，但要设计出真正符合美学方向的作品。
- **限制条件**: 技术要求（框架、性能、可访问性）。

**至关重要**: 选择一个明确的概念方向并精准执行。大胆的极繁主义和精致的极简主义都行之有效——关键在于“刻意为之”，而非“力度大小”。

随后实现具备以下特质的可运行代码（HTML/CSS/JS, React, Vue 等），即：

- 生产级别且功能完备
- 视觉效果惊艳，令人难忘
- 具有清晰的美学观点，风格统一
- 每一个细节都经过精心推敲

## 前端美学指南

核心关注点：

- **字体选择**: 选择美观、独特且引人注目的字体。避免使用 Arial 和 Inter 等通用字体；而应选择能够提升前端美感的独特字体；选择出人意料、富有个性的字体。将醒目的标题字体与精致的正文字体搭配使用。
- **色彩与主题**: 致力于统一的美学风格。使用 CSS 变量保持一致性。主色调配合锐利的强调色，效果远好于平庸、分布均匀的调色板。
- **动态效果**: 使用动画来实现特效和微交互。优先考虑纯 CSS 的 HTML 解决方案。如果 React 有 Motion 库，请使用它。专注于高冲击力时刻：精心设计的页面加载，配合错落有致的动画延迟，比分散的微交互更能带来惊喜。使用滚动触发和悬停状态来制造惊喜。
- **空间构图**: 出人意料的布局。非对称性。元素重叠。斜向流动。打破网格的元素。慷慨的留白，或是受控的密度。
- **背景与视觉细节**: 营造氛围和深度，而非仅仅使用纯色。添加与整体美感相符的上下文效果和纹理。运用渐变网格、噪点纹理、几何图案、分层透明、戏剧性阴影、装饰性边框、自定义光标和颗粒叠加等创意形式。

永远不要使用通用的 AI 生成的美学元素，例如过度使用的字体系列（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（尤其是白色背景上的紫色渐变）、可预测的布局和组件模式，以及缺乏上下文特征的千篇一律的设计。

请发挥创造力进行解读，做出意料之外的选择，让设计真正契合语境。每个设计都不应雷同。尝试浅色和深色主题、不同的字体、不同的美学风格。切勿让不同世代的设计都采用相同的风格（例如 Space Grotesk）。

**重要提示**: 将实现复杂度与美学愿景相匹配。极繁主义设计需要复杂的代码、大量的动画和特效；而极简或精炼的设计则需要克制、精准，并对间距、排版和微妙细节保持高度关注。优雅源于对理念的完美执行。

记住：你完全有能力完成非凡的创意工作。不要有所保留，请全力以赴投入到一个独特的愿景中，展示跳出框架思考时能创造出的真正杰作。
