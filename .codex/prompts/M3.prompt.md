## taroify 组件使用规范

项目已安装 `@taroify/core`，且通过 `vite-plugin-style-import` 配置了**样式自动导入**（引入组件时无需手动 `import` CSS 文件）。

**优先级规则**：

1. **优先使用 taroify 提供的组件**，通过 `className` + SCSS 覆盖将其视觉调整为项目设计规范（soft 色板）
2. 若 taroify 组件的交互结构与设计差异过大，再考虑手写组件
3. 可通过 `@taroify/mcp` MCP 检索可用组件列表和 Props

**本模块适用的 taroify 组件**：

| 用途     | taroify 组件 | import 路径              | 说明                                               |
| -------- | ------------ | ------------------------ | -------------------------------------------------- |
| 状态标签 | `Tag`        | `@taroify/core/tag`      | `shape="rounded"` 实现 pill 形，className 覆盖颜色 |
| 进度条   | `Progress`   | `@taroify/core/progress` | `label={false}` 隐藏文字，className 覆盖颜色和高度 |
| 操作按钮 | `Button`     | `@taroify/core/button`   | className 覆盖颜色匹配设计规范                     |

> ⚠️ **颜色覆盖说明**：taroify 默认为 solid 色板（白色文字 + 纯色背景），项目设计规范为 soft 色板（彩色文字 + 浅色背景）。需通过组件的 `className` prop + SCSS 中更高优先级的选择器（必要时用 `!important`）进行覆盖。

## 子任务 1：实现 StatusTag 组件（使用 taroify `Tag`）

**使用 taroify `Tag`**：提供 pill 形状和语义色，通过 `className` 覆盖为设计规范的 soft 色板。

完整替换 `src/components/StatusTag/index.tsx`：

```typescript
import Tag from '@taroify/core/tag'
import type { ReminderLevel } from '@/types'
import './index.scss'

interface StatusTagProps {
  level: ReminderLevel
  label: string
}

// ReminderLevel 到 taroify Tag color 的映射
// 'paused' 无对应语义色，映射到 'default'（再由 SCSS 覆盖为紫色）
const colorMap = {
  danger: 'danger',
  warning: 'warning',
  good: 'success',
  paused: 'default',
} as const

export default function StatusTag({ level, label }: StatusTagProps) {
  return (
    <Tag
      shape='rounded'
      color={colorMap[level]}
      className={`status-tag status-tag--${level}`}
    >
      {label}
    </Tag>
  )
}
```

## 子任务 2：实现 ProgressBar 组件（使用 taroify `Progress`）

**使用 taroify `Progress`**：提供进度动画结构，通过 `className` 覆盖高度和颜色为设计规范值。

完整替换 `src/components/ProgressBar/index.tsx`：

```typescript
import Progress from '@taroify/core/progress'
import type { ReminderLevel } from '@/types'
import './index.scss'

interface ProgressBarProps {
  /** 进度百分比 0–100 */
  progress: number
  level: ReminderLevel
}

// ReminderLevel 到 taroify Progress color 的映射
// 'paused' 复用 'success'（绿色），视觉上不突出
const colorMap = {
  danger: 'danger',
  warning: 'warning',
  good: 'success',
  paused: 'success',
} as const

export default function ProgressBar({ progress, level }: ProgressBarProps) {
  const barLevel = level === 'paused' ? 'good' : level
  const safePercent = Math.min(100, Math.max(0, progress))

  return (
    <Progress
      className={`progress-bar progress-bar--${barLevel}`}
      percent={safePercent}
      color={colorMap[barLevel]}
      label={false}
    />
  )
}
```

完整替换 `src/components/ProgressBar/index.scss`：

```scss
@use '@/assets/styles/variables' as *;

// taroify Progress 默认高度 28px、颜色与项目设计规范不同
// 通过 className 组合选择器覆盖高度和填充条精确颜色
.progress-bar {
  // 覆盖高度和轨道背景色
  &.taroify-progress {
    height: 8px;
    background: #ecf3f5;
  }

  // 覆盖各状态填充条颜色为设计规范精确色值
  &--danger .taroify-progress__portion {
    background: $danger;
  }

  &--warning .taroify-progress__portion {
    background: $warning;
  }

  &--good .taroify-progress__portion {
    background: $success;
  }
}
```

> **说明**：taroify Progress 默认 danger 颜色为 `#ee0a24`，项目设计值为 `$danger: #c94040`，必须通过 SCSS 覆盖 `.taroify-progress__portion` 的 background 以精确匹配设计稿。

## 子任务 3：实现 MedicineCard 组件（操作按钮使用 taroify `Button`）

**使用 taroify `Button`** 实现操作按钮，通过 `className` 覆盖为设计规范颜色；卡片布局为自定义（taroify 无对应药物卡片组件）。

完整替换 `src/components/MedicineCard/index.tsx`：

```typescript
import { View, Text } from '@tarojs/components'
import Button from '@taroify/core/button'
import type { DerivedReminder } from '@/types'
import StatusTag from '@/components/StatusTag'
import ProgressBar from '@/components/ProgressBar'
import './index.scss'

interface MedicineCardProps {
  item: DerivedReminder
  /** 是否显示操作按钮（首页/列表页均为 true，详情面板中为 false） */
  showActions?: boolean
  onDone?: () => void
  onDetail?: () => void
}

export default function MedicineCard({
  item,
  showActions = true,
  onDone,
  onDetail,
}: MedicineCardProps) {
  // 已开药按钮：逾期/今日用 danger 色，其余用 success 色
  const doneColor = item.level === 'danger' ? 'danger' : 'success'

  return (
    <View
      className={`medicine-card${item.status === 'paused' ? ' medicine-card--paused' : ''}`}
    >
      {/* 顶部：药物名 + 状态标签 */}
      <View className='medicine-card__row'>
        <View className='medicine-card__info'>
          <Text className='medicine-card__name'>{item.name}</Text>
          <Text className='medicine-card__meta'>
            最近开药 {item.lastDate} · 周期 {item.interval} 天 · {item.before} 天前 {item.time} 提醒
          </Text>
        </View>
        <StatusTag level={item.level} label={item.levelLabel} />
      </View>

      {/* 进度条 */}
      <View className='medicine-card__progress'>
        <ProgressBar progress={item.progress} level={item.level} />
      </View>

      {/* 操作按钮（taroify Button） */}
      {showActions && (
        <View className='medicine-card__actions'>
          <Button
            className={`medicine-card__btn medicine-card__btn--${doneColor}`}
            color={doneColor}
            onClick={onDone}
          >
            ✓ 已开药
          </Button>
          <Button
            className='medicine-card__btn medicine-card__btn--ghost'
            onClick={onDetail}
          >
            查看详情
          </Button>
        </View>
      )}
    </View>
  )
}
```

## 子任务 4：实现首页（`src/pages/home/`）

### 4.1 完整替换 `src/pages/home/index.tsx`

```typescript
import Taro, { useLoad } from '@tarojs/taro'
import { View, Text } from '@tarojs/components'

import { useDerivedList, useReminderActions } from '@/hooks/useReminders'
import { formatDisplay, parseDate } from '@/utils/dateUtils'
import AppBar from '@/components/AppBar'
import MedicineCard from '@/components/MedicineCard'

import './index.scss'

export default function Home() {
  const allItems = useDerivedList()
  const { markDone } = useReminderActions()

  // 统计数据（基于派生列表实时计算）
  const overdueCount = allItems.filter(x => x.status !== 'paused' && x.daysLeft < 0).length
  const todayCount = allItems.filter(x => x.status !== 'paused' && x.daysLeft === 0).length
  const total = allItems.length
  const hasDanger = overdueCount > 0 || todayCount > 0

  // 前 3 条紧急活跃提醒（deriveAll 已按优先级排序）
  const urgent = allItems.filter(x => x.status !== 'paused').slice(0, 3)

  // AppBar 副标题：今日日期
  const todayStr = (() => {
    const now = new Date()
    return `${now.getMonth() + 1}月${now.getDate()}日，先处理最紧急的开药任务`
  })()

  const handleMarkDone = (id: string) => {
    markDone(id)
    Taro.showToast({ title: '已记录开药', icon: 'success', duration: 1500 })
  }

  const handleViewAll = () => {
    Taro.switchTab({ url: '/pages/list/index' })
  }

  /** M5 实现后替换为打开新增 BottomSheet */
  const handleAddNew = () => {
    Taro.showToast({ title: '功能开发中', icon: 'none', duration: 1200 })
  }

  /** M6 实现后替换为打开详情 BottomSheet */
  const handleDetail = (_id: string) => {
    Taro.showToast({ title: '详情开发中', icon: 'none', duration: 1200 })
  }

  useLoad(() => {
    console.log('home page loaded')
  })

  return (
    <View className='home-page'>
      {/* 顶部标题栏 */}
      <AppBar
        title='首页总览'
        caption={todayStr}
        right={
          <View className='home-page__header-btn' onClick={handleAddNew}>
            <Text>+</Text>
          </View>
        }
      />

      {/* 风险摘要卡片 */}
      <View className={`home-hero${hasDanger ? ' home-hero--danger' : ''}`}>
        <Text className='home-hero__eyebrow'>今日待办</Text>
        <Text className='home-hero__title'>
          {overdueCount} 个已逾期，{todayCount} 个今天到期
        </Text>
        <Text className='home-hero__desc'>
          {hasDanger
            ? '建议先完成逾期或今日到期事项，再检查未来 7 天内需要提前挂号的药物。'
            : '近期没有紧急开药任务，继续保持当前记录节奏。'}
        </Text>
      </View>

      {/* 统计行：三格数据 */}
      <View className='home-metrics'>
        <View className='home-metric'>
          <Text className='home-metric__value'>{overdueCount}</Text>
          <Text className='home-metric__label'>已逾期</Text>
        </View>
        <View className='home-metric'>
          <Text className='home-metric__value'>{todayCount}</Text>
          <Text className='home-metric__label'>今日处理</Text>
        </View>
        <View className='home-metric'>
          <Text className='home-metric__value'>{total}</Text>
          <Text className='home-metric__label'>管理中</Text>
        </View>
      </View>

      {/* 最近待开药提醒 */}
      <View className='home-subhead'>
        <Text className='home-subhead__title'>最近待开药提醒</Text>
        <View className='home-subhead__action' onClick={handleViewAll}>
          <Text>查看全部</Text>
        </View>
      </View>
      <View className='home-cards'>
        {urgent.length > 0
          ? urgent.map(item => (
              <MedicineCard
                key={item.id}
                item={item}
                onDone={() => handleMarkDone(item.id)}
                onDetail={() => handleDetail(item.id)}
              />
            ))
          : (
              <View className='home-empty'>
                <Text>暂无待处理提醒</Text>
              </View>
            )
        }
      </View>

      {/* 近期时间线 */}
      <View className='home-subhead'>
        <Text className='home-subhead__title'>近期时间线</Text>
        <Text className='home-subhead__note'>下次开药节点</Text>
      </View>
      <View className='home-timeline'>
        {urgent.map(item => {
          const dateLabel =
            item.daysLeft <= 0 ? '今天' : formatDisplay(parseDate(item.nextDate))
          return (
            <View key={`tl-${item.id}`} className='home-timeline__item'>
              <View className='home-timeline__date'>
                <Text>{dateLabel}</Text>
              </View>
              <View className='home-timeline__body'>
                <Text className='home-timeline__name'>{item.name}开药提醒</Text>
                <Text className='home-timeline__desc'>
                  {item.levelLabel} · 预计下次 {item.nextDate}，提醒 {item.remindAt} {item.time}
                </Text>
              </View>
            </View>
          )
        })}
      </View>

      {/* FAB 新增按钮（M5 接入前为 Toast 占位） */}
      <View className='home-fab' onClick={handleAddNew}>
        <Text className='home-fab__icon'>+</Text>
      </View>
    </View>
  )
}
```

## 重要约束

1. **taroify 优先**：有合适的 taroify 组件时必须优先使用，通过 `className` + SCSS 覆盖匹配设计规范；手写组件仅在 taroify 无对应组件时使用
2. **taroify 样式自动导入**：`vite-plugin-style-import` 已配置，引入 taroify 组件时无需手动 `import` CSS 文件
3. **禁止内联色值**：所有颜色通过 SCSS 变量引用，`#fff`（白色文字）为字面量例外；taroify 覆盖场景允许使用 `!important`
4. **Taro 组件**：布局层使用 `@tarojs/components` 中的 `View`、`Text`，不使用 HTML 标签（`div`、`p`、`ul` 等）
5. **不修改 M1/M2 文件**：`src/styles/variables.scss`、`src/app.scss`、`src/types/index.ts`、`src/utils/`、`src/store/`、`src/hooks/` 均不修改
6. **不修改 `index.config.ts`**：首页的页面配置在 M1 已完成
7. **不实现 M5/M6 功能**：FAB 和"查看详情"按钮使用 `Taro.showToast` 占位，并留清晰的 TODO 注释
8. **组件样式独立**：StatusTag、ProgressBar、MedicineCard 各自的样式文件独立，通过 `@use '@/assets/styles/variables' as *` 引入，不依赖 `app.scss` 中的全局 class
9. **`position: fixed` 适用**：微信小程序支持 `position: fixed`，FAB 使用此定位方式
10. **`Taro.switchTab` 路径**：TabBar 页面切换使用 `Taro.switchTab({ url: '/pages/list/index' })`，必须带 `/` 前缀
