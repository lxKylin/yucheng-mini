# M11 · MedicineComposer（统一新增/编辑 Sheet）

## 任务概述

你是一名熟练的 Taro 4 + React 18 + TypeScript + Zustand + @taroify/core 专家。请按照以下规范，**逐步完成** M11 MedicineComposer 统一新增 / 编辑 Sheet 的全部开发内容。完成每个子任务后自行验证，确认无误再进入下一个。

本模块承接 M10 / M10a 的统一 `Medicine` 数据层：用一个 `MedicineComposer` 替代旧 `ReminderForm`，覆盖“新增开药提醒”“新增药品”“编辑药品 / 提醒”三类场景。`reminderEnabled` 开关控制开药提醒配置区展开或折叠；药品基础信息始终保存。

  - FAB 行为：提醒页默认新增开药提醒，药箱页默认新增药品

## 子任务 1：新建 `MedicineComposer` 组件

新建：

- `src/components/MedicineComposer/index.tsx`
- `src/components/MedicineComposer/index.scss`

### 1.1 Props

```typescript
interface MedicineComposerProps {
  medicineId?: string;
  defaultReminderEnabled?: boolean;
  onSuccess: (medicine?: Medicine) => void;
  onCancel: () => void;
}
```

说明：

- 不需要在组件内部再包一层 `BottomSheet`，继续由页面上的 `BottomSheet` 承载
- `medicineId` 有值时为编辑模式，通过 `useDerivedById(medicineId)` 回填
- `defaultReminderEnabled` 仅在新增模式生效：
  - 首页 / 提醒列表：传 `true`
  - 药箱新增入口：传 `false`
- `onSuccess` 在新增或更新成功后调用，页面负责关闭 Sheet

### 1.2 表单状态

组件内部维护完整 Medicine 表单值，至少包含：

```typescript
interface FormValues {
  name: string;
  spec: string;
  form: MedicineForm;
  expiryDate: string;
  note: string;
  dosagePerUse: number;
  dosageUnit: DosageUnit;
  timesPerDay: number;
  scheduleTiming: MedicineSchedule;
  scheduleTime: string;
  reminderEnabled: boolean;
  currentPrescriptionDate: string;
  intervalDays: number;
  remindAdvanceDays: number;
  remindTime: string;
}
```

默认值：

- `name`: `''`
- `spec`: `''`
- `form`: `'tablet'`
- `expiryDate`: `''`
- `note`: `''`
- `dosagePerUse`: `1`
- `dosageUnit`: `'片'`
- `timesPerDay`: `1`
- `scheduleTiming`: `'饭后'`
- `scheduleTime`: `'08:00'`
- `reminderEnabled`: `defaultReminderEnabled ?? false`
- `currentPrescriptionDate`: `today()`
- `intervalDays`: `DEFAULT_INTERVAL`
- `remindAdvanceDays`: `loadSettings().defaultBefore || DEFAULT_BEFORE`
- `remindTime`: `loadSettings().defaultTime || DEFAULT_REMIND_TIME`

编辑模式回填所有字段，尤其是：

- `expiryDate`
- `form`
- `dosagePerUse`
- `dosageUnit`
- `timesPerDay`
- `scheduleTiming`
- `scheduleTime`
- `reminderEnabled`
- `currentPrescriptionDate`
- `intervalDays`
- `remindAdvanceDays`
- `remindTime`
- `note`

## 子任务 2：实现表单分区与交互

### 2.1 基础信息区

字段：

- 药品名称：`Input`，必填
- 规格：`Input`
- 剂型：`Picker`，使用 `MEDICINE_FORM_OPTIONS`
- 过期时间：`Picker mode="date"`，允许为空
- 备注：`Textarea`

### 2.2 服药信息区

字段：

- 每次用量：数字输入或 Stepper，最小值建议 `0.5` 或 `1`，避免负数
- 单位：`Picker`，使用 `DOSAGE_UNIT_OPTIONS`
- 每日次数：数字输入或 Stepper，范围 `1–6`
- 服用时机：`Picker`，使用 `SCHEDULE_OPTIONS`
- 具体时间点：仅当 `scheduleTiming === '固定时间'` 时展示，使用 `Picker mode="time"`，默认 `08:00`

交互要求：

- 非“固定时间”时隐藏具体时间点，并在提交 payload 中将 `scheduleTime` 置为 `''`
- 切换回“固定时间”时，如果没有时间值，回填 `08:00`

### 2.3 开药提醒区

顶部使用开关控件展示：

- 标题：“开药提醒”
- 辅助文案：“开启后会进入首页风险中心和提醒列表”
- 开关状态绑定 `reminderEnabled`

当 `reminderEnabled=false`：

- 提醒配置区折叠
- 提交后保存为纯药箱药品
- `currentPrescriptionDate` / `intervalDays` / `remindAdvanceDays` / `remindTime` 仍写入稳定默认值，不能留空导致派生报错

当 `reminderEnabled=true`：

展开字段：

- 最近开药日期：`Picker mode="date"`
- 开药间隔：数字输入 + 快捷按钮，使用 `INTERVAL_OPTIONS`
- 提前提醒天数：`Picker` 或快捷按钮，使用 `BEFORE_OPTIONS`
- 提醒时刻：`Picker mode="time"`

实时预算提示：

```text
预计下次开药日期：YYYY-MM-DD · 提醒日：MM-DD HH:mm
```

实现要求：

- 使用 `calcNextDate()` / `calcRemindDate()` 计算
- 字段变化时即时更新
- `intervalDays` 非法时展示“请输入 1-365 之间的开药间隔”

## 子任务 3：提交、校验与 Store 写入

### 3.1 校验

提交时必须校验：

- 药品名称不能为空，失败 Toast：“请填写药品名称”
- `dosagePerUse` 必须大于 0，否则 Toast：“每次用量需大于 0”
- `timesPerDay` 范围为 `1–6`，否则 Toast：“每日次数需在 1-6 次之间”
- `reminderEnabled=true` 时：
  - `intervalDays` 范围为 `1–365`
  - `currentPrescriptionDate` 不能为空
  - `remindTime` 不能为空

### 3.2 新增 payload

新增时调用 `addReminder()`，传入完整 Medicine 字段：

```typescript
{
  name,
  spec,
  form,
  expiryDate,
  note,
  dosagePerUse,
  dosageUnit,
  timesPerDay,
  scheduleTiming,
  scheduleTime,
  reminderEnabled,
  currentPrescriptionDate,
  intervalDays,
  remindAdvanceDays,
  remindTime,
  status: REMINDER_STATUS.ACTIVE,
  prescriptionHistory: reminderEnabled ? [currentPrescriptionDate] : [],
  lastWechatReminderDate: '',
  lastWechatReminderAt: ''
}
```

Toast：

- `reminderEnabled=true`：`开药提醒已创建`
- `reminderEnabled=false`：`药品已保存到药箱`

### 3.3 编辑 payload

编辑时调用 `updateReminder(medicineId, payload)`。

要求：

- 更新所有表单字段
- 如果从 `reminderEnabled=false` 切换为 `true`，且 `prescriptionHistory` 为空，不强制补历史；只确保 `currentPrescriptionDate` 稳定存在
- 如果从 `reminderEnabled=true` 切换为 `false`，不要清空开药配置和历史记录，只更新 `reminderEnabled=false`
- Toast：`药品已更新`

### 3.4 成功回调

新增 / 编辑成功后：

- 调用 `onSuccess(savedMedicine?)`
- 页面关闭 BottomSheet
- 不在组件内部直接操作页面路由
