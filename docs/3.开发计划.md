## M2 · 数据层 & 业务逻辑

### 目标

定义核心数据类型、状态管理、日期计算工具函数，为所有页面提供统一数据来源。

### 开发内容

#### 1. 类型定义（`src/types/index.ts`）

```typescript
/** 提醒状态 */
export type ReminderStatus = 'active' | 'paused' | 'deleted';

/** 提醒紧急等级（用于 UI 颜色） */
export type ReminderLevel = 'danger' | 'warning' | 'good' | 'paused';

/** 药物提醒主体 */
export interface Reminder {
  id: string;
  name: string; // 药物名称
  spec: string; // 规格描述
  lastDate: string; // 最近开药日期 YYYY-MM-DD
  interval: number; // 开药间隔（天）
  before: number; // 提前提醒天数
  time: string; // 提醒时间 HH:mm
  status: ReminderStatus;
  note: string; // 备注
  history: string[]; // 历史开药日期列表（最近 5 条）
  createdAt: string;
  updatedAt: string;
}

/** 派生计算数据（不持久化） */
export interface DerivedReminder extends Reminder {
  nextDate: string; // 预计下次开药日期
  remindAt: string; // 实际触发提醒日期
  daysLeft: number; // 距今天数（负数=逾期）
  level: ReminderLevel;
  levelLabel: string; // "5 天后" / "逾期 2 天" / "今日" / "已暂停"
  progress: number; // 进度条百分比 0-100
}

/** 历史开药记录 */
export interface PrescriptionRecord {
  id: string;
  reminderId: string;
  prescriptionDate: string;
  note: string;
  createdAt: string;
}

/** 通知记录（用于“我的”页内消息收件箱） */
export interface NotificationRecord {
  id: string;
  reminderId: string;
  title: string;
  summary: string;
  date: string; // YYYY-MM-DD
  time: string; // HH:mm
  category: 'urgent' | 'upcoming' | 'archive';
  read: boolean;
  createdAt: string;
}
```

#### 2. 日期工具函数（`src/utils/dateUtils.ts`）

```typescript
// 关键函数：
addDays(date, days): Date          // 日期加法
diffDays(from, to): number         // 两日期差值（天）
formatDate(date): string           // 格式化为 YYYY-MM-DD
formatDisplay(date): string        // 格式化为 M月D日
calcNextDate(lastDate, interval)   // 计算下次开药日期
calcRemindDate(nextDate, before)   // 计算提醒触发日期
derive(reminder): DerivedReminder  // 核心派生函数（单条）
deriveAll(reminders): DerivedReminder[]  // 批量派生并排序
```

**排序规则**（与 UI6.0 一致）：

```
danger(逾期/今日) < warning(7天内) < good(正常) < paused(暂停)
同级按 nextDate 升序
```

#### 3. 状态管理（`src/store/reminderStore.ts`）

使用 Zustand，MVP 阶段使用本地存储模拟，云开发集成后替换为 API 调用：

```typescript
interface ReminderStore {
  reminders: Reminder[];
  notifications: NotificationRecord[];
  // CRUD
  addReminder: (
    payload: Omit<Reminder, 'id' | 'createdAt' | 'updatedAt'>
  ) => void;
  updateReminder: (id: string, payload: Partial<Reminder>) => void;
  deleteReminder: (id: string) => void;
  // 业务操作
  markDone: (id: string, date?: string) => void; // 已开药，更新 lastDate 并推进周期
  togglePause: (id: string) => void; // 切换暂停/启用
  markNotificationRead: (id: string) => void;
  markAllNotificationsRead: () => void;
  // 查询（返回派生数据）
  getDerivedList: () => DerivedReminder[];
  getById: (id: string) => DerivedReminder | null;
  getInboxList: () => NotificationRecord[];
}
```

#### 4. 本地持久化（`src/utils/storage.ts`）

- 封装 `Taro.setStorageSync` / `Taro.getStorageSync`
- key: `reminders_v1`
- key: `notification_inbox_v1`
- store 初始化时读取，每次修改后写入

#### 5. 常量（`src/constants/index.ts`）

```typescript
// 快捷间隔选项
INTERVAL_OPTIONS = [7, 14, 30, 45, 60, 90];
// 快捷提前天数
BEFORE_OPTIONS = [1, 3, 7, 14];
// 默认值
DEFAULT_REMIND_TIME = '09:00';
DEFAULT_INTERVAL = 30;
DEFAULT_BEFORE = 3;
```

### 验收标准

- [ ] `derive()` 函数可正确计算 nextDate、remindAt、daysLeft、level、progress
- [ ] 边界场景测试：今天到期（daysLeft=0）→ level=danger；逾期（daysLeft<0）→ level=danger；7天内 → warning；7天以上 → good；paused → paused
- [ ] `addReminder` 后通过 `getDerivedList` 可查到新数据
- [ ] `markDone` 后 lastDate 更新为当天，history 插入今日日期

## M6 · 提醒详情模块

查看单个提醒完整信息，支持已开药、暂停/启用、编辑、删除操作。

### UI 参考

**操作按钮组**

- 本次已开药（主按钮）

**信息网格（2x2）**

- 最近开药日期

### M10 · 统一数据层重构

#### 目标

#### 开发内容

##### 1. 类型重构（`src/types/index.ts`）

**新增枚举类型：**

```typescript
export type MedicineForm =
  | 'tablet'
  | 'capsule'
  | 'liquid'
  | 'injection'
  | 'external'
  | 'patch'
  | 'other';

export type DosageUnit = '片' | '粒' | 'ml' | '支' | '贴';

export type MedicineSchedule =
  | '饭前'
  | '饭后'
  | '随餐'
  | '空腹'
  | '睡前'
  | '固定时间';

/** 药品状态（原 ReminderStatus） */
export type MedicineStatus = 'active' | 'paused' | 'deleted';
```

**`Reminder` → `Medicine` 重命名 + 字段扩展：**

```typescript
export interface Medicine {
  id: string;

  // ── 基础信息（原字段，重命名）──────────────────────────────────────
  name: string; // 原 medicineName
  spec: string; // 原 medicineSpec
  form: MedicineForm; // 新增，默认 "tablet"
  expiryDate: string; // 过期时间 YYYY-MM-DD，可为空
  note: string;

  // ── 服药信息（新增，全部选填，0/空字符串为未填）───────────────
  dosagePerUse: number; // 每次用量数，默认 1
  dosageUnit: DosageUnit; // 用量单位，默认 "片"
  timesPerDay: number; // 每日次数，默认 1
  scheduleTiming: MedicineSchedule; // 服用时机
  scheduleTime: string; // 固定时间时的具体时间 HH:mm，可为空

  // ── 开药提醒（原字段保留，reminderEnabled 控制是否生效）──────────
  reminderEnabled: boolean; // 新增，默认 false；存量数据迁移时赋 true
  currentPrescriptionDate: string;
  intervalDays: number;
  remindAdvanceDays: number;
  remindTime: string;
  status: MedicineStatus;
  prescriptionHistory: string[];
  lastWechatReminderDate: string;
  lastWechatReminderAt: string;

  createdAt: string;
  updatedAt: string;
}

/** 派生数据（不持久化） */
export interface DerivedMedicine extends Medicine {
  // 提醒派生（reminderEnabled=true 时有意义）
  nextPrescriptionDate: string;
  nextRemindDate: string;
  daysLeft: number;
  level: ReminderLevel;
  levelLabel: string;
  progress: number;
  scheduleLabel: string; // 如 "固定时间 20:00"
}
```

> 为保持向后兼容，可导出 `type Reminder = Medicine`、`type DerivedReminder = DerivedMedicine` 别名。但类型别名不能自动兼容字段名差异，仍需通过 `migrateMedicine()` 同时读取 `name/spec` 与旧字段 `medicineName/medicineSpec`，组件层再分批替换字段引用。
