## M2 · 数据层 & 业务逻辑

### 目标

定义核心数据类型、状态管理、日期计算工具函数，为所有页面提供统一数据来源。

### 开发内容

#### 1. 类型定义（`src/types/index.ts`）

```typescript
/** 提醒状态 */
export type ReminderStatus = "active" | "paused" | "deleted";

/** 提醒紧急等级（用于 UI 颜色） */
export type ReminderLevel = "danger" | "warning" | "good" | "paused";

/** 药物提醒主体 */
export interface Reminder {
  id: string;
  name: string; // 药物名称
  spec: string; // 规格描述
  lastDate: string; // 最近开药日期 YYYY-MM-DD
  interval: number; // 开药间隔（天）
  before: number; // 提前提醒天数
  time: string; // 提醒时间 HH:mm
  status: ReminderStatus;
  note: string; // 备注
  history: string[]; // 历史开药日期列表（最近 5 条）
  createdAt: string;
  updatedAt: string;
}

/** 派生计算数据（不持久化） */
export interface DerivedReminder extends Reminder {
  nextDate: string; // 预计下次开药日期
  remindAt: string; // 实际触发提醒日期
  daysLeft: number; // 距今天数（负数=逾期）
  level: ReminderLevel;
  levelLabel: string; // "5 天后" / "逾期 2 天" / "今日" / "已暂停"
  progress: number; // 进度条百分比 0-100
}

/** 历史开药记录 */
export interface PrescriptionRecord {
  id: string;
  reminderId: string;
  prescriptionDate: string;
  note: string;
  createdAt: string;
}
```

#### 2. 日期工具函数（`src/utils/dateUtils.ts`）

```typescript
// 关键函数：
addDays(date, days): Date          // 日期加法
diffDays(from, to): number         // 两日期差值（天）
formatDate(date): string           // 格式化为 YYYY-MM-DD
formatDisplay(date): string        // 格式化为 M月D日
calcNextDate(lastDate, interval)   // 计算下次开药日期
calcRemindDate(nextDate, before)   // 计算提醒触发日期
derive(reminder): DerivedReminder  // 核心派生函数（单条）
deriveAll(reminders): DerivedReminder[]  // 批量派生并排序
```

**排序规则**（与 UI5.0 一致）：

```
danger(逾期/今日) < warning(7天内) < good(正常) < paused(暂停)
同级按 nextDate 升序
```

#### 3. 状态管理（`src/store/reminderStore.ts`）

使用 Zustand，MVP 阶段使用本地存储模拟，云开发集成后替换为 API 调用：

```typescript
interface ReminderStore {
  reminders: Reminder[];
  // CRUD
  addReminder: (payload: Omit<Reminder, "id" | "createdAt" | "updatedAt">) => void;
  updateReminder: (id: string, payload: Partial<Reminder>) => void;
  deleteReminder: (id: string) => void;
  // 业务操作
  markDone: (id: string, date?: string) => void; // 已开药，更新 lastDate 并推进周期
  togglePause: (id: string) => void; // 切换暂停/启用
  // 查询（返回派生数据）
  getDerivedList: () => DerivedReminder[];
  getById: (id: string) => DerivedReminder | null;
}
```

#### 4. 本地持久化（`src/utils/storage.ts`）

- 封装 `Taro.setStorageSync` / `Taro.getStorageSync`
- key: `reminders_v1`
- store 初始化时读取，每次修改后写入

#### 5. 常量（`src/constants/index.ts`）

```typescript
// 快捷间隔选项
INTERVAL_OPTIONS = [7, 14, 30, 45, 60, 90];
// 快捷提前天数
BEFORE_OPTIONS = [1, 3, 7, 14];
// 默认值
DEFAULT_REMIND_TIME = "09:00";
DEFAULT_INTERVAL = 30;
DEFAULT_BEFORE = 3;
```

### 验收标准

- [ ] `derive()` 函数可正确计算 nextDate、remindAt、daysLeft、level、progress
- [ ] 边界场景测试：今天到期（daysLeft=0）→ level=danger；逾期（daysLeft<0）→ level=danger；7天内 → warning；7天以上 → good；paused → paused
- [ ] `addReminder` 后通过 `getDerivedList` 可查到新数据
- [ ] `markDone` 后 lastDate 更新为当天，history 插入今日日期
- [ ] `togglePause` 正确切换 status
- [ ] 数据在小程序退出后重启可恢复（本地存储）

## M9 · 微信云开发集成

### 目标

替换本地存储为云数据库，实现微信订阅消息定时推送，完成真实的提醒闭环。

> **前提**：M1-M8 全部验收通过，所有接口调用已抽象为 `services/` 层

### 开发内容

#### 1. 云开发初始化

- 创建云开发环境
- 配置 `project.config.json` 中 `cloudbaseRoot`
- 初始化 `src/services/cloud.ts`

#### 2. 用户认证（`src/services/auth.ts`）

- 调用 `Taro.login()` 获取 code
- 调用云函数 `auth` 换取 openid，写入 user 集合
- 全局 store 存储 userId

#### 3. 数据服务层（`src/services/reminder.ts`）

替换 store 中的本地存储调用为云数据库 CRUD：

```
getList()       → db.collection('medicines').where({ userId }).get()
add(payload)    → db.collection('medicines').add()
update(id, payload) → db.collection('medicines').doc(id).update()
remove(id)      → db.collection('medicines').doc(id).remove()
```

#### 4. 云函数：reminder（定时扫描推送）

- 触发器：每天 08:00、09:00、10:00 各执行一次（覆盖不同提醒时间设置）
- 逻辑：查询 `nextRemindDateTime` 在今天的记录 → 调用微信订阅消息 API 发送

```javascript
// 提醒消息模板参数：
{
  thing1: 药物名称,       // 提醒药品
  time2: 预计开药日期,    // 建议开药时间
  thing3: 提前N天提醒说明 // 提醒原因
}
```

#### 5. 云函数：auth

- 微信登录换 openid
- 新用户自动创建 user 记录

#### 6. 订阅消息授权（`src/pages/profile/`）

- 调用 `Taro.requestSubscribeMessage()` 申请授权
- 处理用户拒绝情况，给出友好提示

### 验收标准

- [ ] 微信登录可获取 openid，用户记录写入云数据库
- [ ] 添加提醒后数据保存在云数据库，关闭重启后数据不丢失
- [ ] 编辑、删除操作同步更新云数据库
- [ ] 云函数 `reminder` 本地调试可触发，日志显示扫描到期记录
- [ ] 订阅消息授权流程完整：用户授权 → 到点发送 → 微信收到消息 → 点击跳转小程序
- [ ] 用户未授权时，小程序内提醒中心仍正常展示

## 设计规范提醒

| 规范项   | 说明                                                          |
| -------- | ------------------------------------------------------------- |
| 颜色     | 严格使用 SCSS 变量，禁止内联色值                              |
| 字号     | 标题 17-24px，正文 14-15px，辅助 12px，大字 44px（剩余天数）  |
| 间距     | 统一 8px/12px/16px/18px 体系                                  |
| 圆角     | 卡片 8px，标签/按钮 999px（pill 形）                          |
| 状态颜色 | danger=#c94040，warning=#b26412，good=#18845d，paused=#6268c9 |
| 动效     | 保持克制，仅 BottomSheet 入场和 Toast 使用动画                |
| 无障碍   | 所有 icon-only 按钮需 aria-label，状态变化用 role=status      |
